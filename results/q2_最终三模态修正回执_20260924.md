# 第二问最终方案修正：三模态输入

## 修正缘由

赛题问题二要求针对**文本、语音、视觉**局部连续时段缺失建立鲁棒多模态模型，并分析不同缺失模态。此前仅凭 valid 综合 J 最低，把只读取文本和视觉的 TV 模型定为主模型，是任务约束与指标取舍中的错误：只遮音频时 TV 输入完全不变，无法用它解释音频缺失的影响。原 `results/q2_locked_test_20260924/模型锁定与测试协议.md` 和测试数据保持原样，不追改历史。

根据用户明确要求，最终方案改用**已训练的三模态分支 Transformer C**：分别用时序编码器处理 50 个对齐位置的文本 768 维、音频 74 维、视觉 35 维，依据各模态有效位置掩码做时序汇聚，拼接三个模态表示与覆盖率，再共享分类、强度预测头。它在附件二 train 学习；每轮对局部连续缺失做增强，valid 选最佳轮，三个种子等权集成。TV 保留为两模态消融对照。

老师建议的**三模态分支、有效位置掩码、连续缺失增强、双任务输出**已实现；可靠性门控也做过三种子对照，但本次训练的门控版 valid 综合分数和 F1 较差，最终采用直接拼接。课程式缺失率、表示一致性、门控稳定约束并未作为最终模型的一部分；不能写成完整照搬老师方案。

## 固定模型与实测

最终三模态 C 使用原 `q2_c_aug_1layer_concat_eff_step9_lr3e4_20260924_seed_{20260923,20260924,20260925}` 三份权重，未重新训练、未改超参数。它在附件二 valid 三种子均值：综合 J `0.6141`，原样 macro-F1 `0.6164`，54 种连续遮蔽平均 macro-F1 `0.5889`、强度 MAE `0.6350`。TV 对照 J `0.6097`，所以**valid 综合分数并未证明三模态 C 更优**。C 的附件二 test 结果在切换角色前已作为固定对照一次性算出：727 条原样 Accuracy `0.6602`、macro-F1 `0.6136`、强度 MAE `0.6381`；54 场景平均 macro-F1 `0.5899`、MAE `0.6759`。未再次运行 test。

**时间顺序必须如实写：**原测试前锁定协议把 TV 列为主模型、C 列为固定对照；本次将 C 改作最终任务模型发生在 test 已揭示之后，理由是题目三模态输入要求，而非重新调参。不能再把“C 被定为最终模型”称为测试前盲选，也不能把已看过的 test 当作这次角色修正的全新独立选模证据。两模型全部 test 结果仍见 `results/q2_locked_test_20260924/test_model_metrics.csv`。

三模态并不等于音频作用已经充分学好。在 test 的九个“仅遮音频”场景里，C 的平均 macro-F1 `0.6129`，接近原样 `0.6136`；音频独立影响较小。论文应写成当前模型的实测现象，不能宣称音频贡献很大。与此对应，文字缺失的平均 F1 明显下降。

## 附件三最终预测

已使用这三份**三模态 C 权重**读取附件三对齐版 30 条无标签样本，输出 `results/q2_attachment3_three_modal_20260924/predictions.csv`，负向 6、中性 9、正向 15；原 TV 预测保留在 `results/q2_attachment3_locked_20260924/` 作为历史对照。两模型 30 条里有 6 条极性不同，不能据此判断谁正确，因为附件三无标签。

处理时用固定版本 BERT 由 `text_bert` 重建缺失的 768 维文字向量；音频、视觉原始全零行按疑似不可观测处理。原始附件前后各 245 项完整性核验均 PASS，训练权重与原始输入未修改，程序退出码 `0`。附件三没有 Accuracy、F1、MAE 或 Pearson 可计算。
