# 第二问分模态时序模型：训练前固定的实验协议

本协议在分模态时序模型完整训练前写定。只用附件二 `aligned_50.pkl` 的 train 3395 条拟合参数、valid 728 条选轮与比较；附件二 test、附件三/四和问题一特征均不参与训练或选型。

1. **共同结构**：文字 768、音频 74、画面 35 维特征分别投影至 96 维；各用独立的 1 层、4 头 Transformer（前馈 192，dropout 0.1）沿有效 token 顺序编码，只汇聚本模态实际可观测的位置。全缺失模态输出零摘要，不让其填充或全零位置进入有效池化。融合后用共享 128 维层输出三分类和 `3*tanh` 强度。
2. **唯一结构变量**：C_concat 将三模态摘要与覆盖率直接拼接；C_gate 对三模态摘要和覆盖率计算样本级权重，只在可用模态间归一化，然后加权融合。两版的编码器、损失、训练预算、种子和验证面板完全相同。原早融合 Transformer、TAV/TV MLP 保留为外部对照。
3. **训练**：固定种子 20260923、20260924、20260925；每种配置各跑 30 轮，不提前停止，记录最小验证 J 的权重。AdamW 学习率 `1e-3`、权重衰减 `1e-2`、batch 64；按 train 类别频次给三分类交叉熵加权，同时用 Huber 训练强度。每个 batch 同时输入完整视图和一个局部遮蔽视图，两者分别对真实标签负责；尚不加一致性损失或课程调度。
4. **局部遮蔽**：只从有效 token 中选长度 10%、30%、50% 的连续段，随机起点；75% 选单模态，25% 选双模态。新规则要求选中段实际丢失至少一行原本可观测的特征，且样本仍保有可观测信息；记录回退数。文字需先把选中 token ID 换成 `[MASK]`，由同一冻结 BERT 重编码；音视频通过全零行等价的可用性掩码排除。仅对 train 制造训练遮蔽。
5. **验证**：预先固定的 54 场景（六种缺失模态组 × 前中后三位置 × 10/30/50% 长度）和完整 valid 均逐轮评估。`J` 只作为既定选轮/选型分数；正式报告 Accuracy、macro-F1、三类各自 F1、MAE、Pearson 及缺失相对完整的下降量。比较三种子配对差值和各缺失类型/位置/长度；不因单个最好种子宣称胜出。
6. **进入后续损失实验的条件**：先完成 C_concat 与 C_gate 的相同预算对照。若两者均未在主要验证指标上给出可信改善，则保留失败结果，不将门控、一致性和课程训练同时堆入最终模型。无论结论如何，附件三只用于模型锁定后的最终全量推理与 CSV 输出。

训练前检查：`src.q2_train_transformer --selfcheck`、附件二音视频整行置零/内部掩码等价检查及小样本试跑都必须通过；每次完整训练前后核验原始附件完整性，终端逐轮打印损失与完整/缺失验证指标。
