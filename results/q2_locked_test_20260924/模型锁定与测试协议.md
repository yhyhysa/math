# 第二问附件二 test：首次查看前的锁定协议

本文件在读取附件二 **test 的标签和预测表现之前**写定。此前仅用 train 拟合、valid 选轮和比较。valid 原有全零行及 54 场景敏感性检查见 `results/q2_valid_missing_audit_20260924_v2/人工审查结论.md`；原定 54 场景和去掉 TV 完全无效的 A-only 9 场景后，TV 旧增强架构的三种子平均 J 均较低。

1. **主模型固定**：`q2_aug_TV_step4_20260924_seed_{20260923,20260924,20260925}` 三份已保存最佳权重，模型只使用文字＋视觉。预测时先对每个权重的三分类 logits 做 softmax，再对三个概率向量等权平均、取最大概率类别；三份强度输出直接等权平均。模型参数和归一化统计一律使用已保存权重，不重新训练。
2. **固定对照**：`q2_c_aug_1layer_concat_eff_step9_lr3e4_20260924_seed_{20260923,20260924,20260925}` 三份权重，三模态分支、直接拼接、学习率 `3e-4`。用同样的三种子等权概率／强度平均；它是科学对照，不依据 test 成绩改为主模型。
3. **唯一 test 评估**：附件二 `aligned_50.pkl` 的 test 727 条标签只读取一次，分别在原始 test 和与 valid 相同的 54 个连续遮蔽场景上计算三分类 Accuracy、macro-F1、各类 F1、强度 MAE、Pearson 及原定义 J；另外分列原本有／无有效位置全零行的表现。所有场景共享同一测试样本，不把 54 场景当独立样本。
4. **输入与核验**：原始附件和模型文件只读；训练统计量从权重读取。输入文件和 BERT 权重核对既定 SHA-256，处理前后核验 245 项原始附件完整性。与 valid 已保存的推理路径一致；不使用附件一、附件三/四或问题一特征。
5. **判读约束**：test 只用于报告独立结果与模型是否泛化，不能再用来改超参数、改主模型、挑种子或改变上述等权规则。无论哪个模型在 test 上更好，都如实报告。附件三没有标签，随后只用锁定主模型作预测。
