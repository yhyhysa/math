# 第二问第二步：连续缺失增强对照（2026-09-24）

## 这一步实际做了什么

在第一步模型 A（三分类 + 强度回归的同一 MLP）上，只给 **train** 增加连续缺失视图；每条样本同时用完整视图和缺失视图训练。文字缺失先替换 token ID 并用冻结 BERT 重编码；音频、画面按有效位掩码汇聚。**valid** 使用与无增强基线相同的 54 个固定场景。附件二 test、附件三、第一问特征均未用于训练或选轮。类别仍是 **0=Negative、1=Neutral、2=Positive**，强度另行预测。

无增强与增强各采用相同的三个种子，均跑满 30 轮，并各自保留 valid 综合分数 J 最低的一轮。正式增强运行的三个 exit_code.txt 都是 **0**，history.csv 均有 **30** 行，每个 scenario_metrics.csv 均有 **54** 行；原始附件在每次训练前后均为 **245 项 PASS**。独立 P1 最小链路审查为 **PASS**。比较脚本还核对了数据与 BERT 哈希、模型名、参数量、train/valid 样本数、种子、轮数和场景定义；不一致会停止。

## 新旧配对结果

表中箭头是“无增强 → 增强”，数值来自 paired_seed_metrics.csv：

| 种子 | 最佳 J ↓ | 完整 valid macro-F1 ↑ | 缺失 54 场景平均 macro-F1 ↑ | 缺失场景平均 MAE ↓ |
|---|---:|---:|---:|---:|
| 20260923 | 0.6284 → 0.6164 | 0.5934 → 0.5996 | 0.5737 → 0.5801 | 0.6248 → 0.6108 |
| 20260924 | 0.6175 → 0.6232 | 0.6127 → 0.6098 | 0.5808 → 0.5777 | 0.6227 → 0.6316 |
| 20260925 | 0.6219 → 0.6204 | 0.6137 → 0.6039 | 0.5781 → 0.5799 | 0.6314 → 0.6243 |

三个种子的**配对平均变化**（增强减无增强）：J **-0.00257**，其种子间样本标准差 **0.00893**；完整 valid 的 Accuracy **-0.00824**、macro-F1 **-0.00221**、MAE **-0.01048**、Pearson **-0.00763**；缺失场景平均 Accuracy **-0.00075**、macro-F1 **+0.00165**、MAE **-0.00403**、Pearson **-0.00803**。J 与缺失 F1/MAE 的平均数略有改善，但波动大于 J 的平均改善，且完整样本分类和相关性退步。因此，这轮**不能宣称稳健性已稳定提升**。

54 个场景中，增强版有 **27/54** 个场景 macro-F1 更高、**35/54** 个场景 MAE 更低；二者并非同一组场景。按缺失模态分组：遮文字的场景平均 F1 增约 **0.0063**，但 MAE 增约 **0.0024**；只遮音频或视觉的场景 MAE 平均降约 **0.0100**、**0.0112**，F1 则略降。具体模态、前中后位置和 10%/30%/50% 长度的全部数字见 scenario_delta.csv，不应只挑有利场景。

三分类的完整 valid 逐类 F1 均值也值得注意：无增强时 Negative **0.6524**、Neutral **0.4586**、Positive **0.7088**；增强后分别是 **0.6437**、**0.4716**、**0.6979**。Neutral 有小幅改善，但仍是最弱一类；不要把强度回归值的正负当作三分类结果。

## 你如何人工审查

1. 打开 paired_seed_metrics.csv，先按相同种子看 J、完整样本指标、缺失指标三组列。delta 一律是“增强减无增强”：F1/Accuracy/Pearson 为正、MAE/J 为负才是该项改善。
2. 打开 scenario_delta.csv，按 modalities、position、ratio 筛选，检查是否只在某些缺失条件下有效。54 行都是 valid 面板的配对比较，长度单位是内容 token 的比例，**不是视频秒数**。
3. 打开各增强目录的 history.csv 和 terminal.log，看每轮训练总损失、分类损失、回归损失、完整与缺失 valid 指标。best_epoch 对应的权重在同名 checkpoints 目录；第 30 轮不一定是最佳。
4. 打开 mask_history.csv，确认各轮都有单模态、双模态遮蔽，fallback_clean 和新增丢失比例合理。若要查某个模型为何选中某轮，先查 summary.json 的 best_epoch 和 best.selection_J。

本轮说明的是**同一小型 MLP 在有无增强时的差别**，还没有完成保留时间顺序的模型 B，也没有对附件三产生最终预测。当前只有三个训练种子，不能从微小平均差推出统计上稳定的优势。下一步应按原建模合同训练时序主模型，并在同一验证面板上比较。
