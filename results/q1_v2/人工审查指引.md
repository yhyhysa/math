# Q1 新版候选：人工审查指引

当前新版是**候选结果**。程序已经验证 100 个文件的结构、哈希和新旧不变数组，但自动覆盖率无法判断“人脸是不是正在说话的人”，也无法证明词边界准确。请先看 `q1_version_comparison.json`、`q1_face_review_priority.csv` 和 `q1_manual_review_sheet.csv`。

下面提到的原视频帧审查图和人脸框拼图已在本机准备好；因含可识别人物画面，本次 Git 更新没有上传这些图。只有仓库的队友需要另备题目授权的原视频并按 `运行使用说明.md` 第 8 节重画。

## 建议审查顺序

1. 打开 `q1_face_review_priority.csv`，按 `priority` 从上往下看，共 **32 段**：前 27 段是被裁剪改变的片段，后 5 段是仍然零人脸的片段。表中有旧/新人脸帧数、词级视觉有效位置及原视频路径。
2. 对采用裁剪的每段，打开 `../q1_v2_face_contact_sheets/<样本ID>_<visual_mode>.png`。图中四张抽样帧的绿色框应落在**正在讲话的目标人物**脸上。特别留意电视画面、旁白、多人同框、画面切换和只拍到听众的情况。`-HwX2H8Z4hY$_$9` 是需要特别核对的电视画面示例：检到电视里的人脸，不等于确认他是当前音频的说话人。
3. 对每段打开 `q1_review_figures/` 的四层图；本次 32 段重点视频都已生成 PNG 和 SVG。也可按 `运行使用说明.md` 中第 4 节命令指定 `--variant q1_v2` 重画。先对照原画面和人脸点位，再**播放原视频并听音频**，检查蓝/橙词块是否与实际发音相邻。静态音量曲线只能提示位置，不能替代听音。
4. 在 `q1_manual_review_sheet.csv` 中填写该段的“整段”行和 `crop_face_identity_review` / `low_face_coverage` / 低可信词的异常行。“人工判定”建议统一填 `通过`、`错人`、`词边界错误`、`无法判断` 之一；有错误时填修正时间、备注和审查者。**填写前另存人工版**，因为重跑制表脚本会覆盖模板。
5. 32 段重点视频完成后，继续核对表中其余词对齐异常和其余片段，尤其抽查自动 `PASS` 样本。只有人工标注有了实际词边界和目标人物判定，才能进一步计算人工词边界误差、目标人脸正确率等准确性指标。
